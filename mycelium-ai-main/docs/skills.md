# Skills (BIG #11-15, Phase 3) — IMPLEMENTED

Evidence-based skills: DISCOVERED → INTERESTED →
LEARNING → PRACTICING → APPLIED → DEMONSTRATED →
MASTERED. No AI mastery claims: `applied` needs
evidence, `demonstrated`/`mastered` need ≥2 evidence
entries plus human confirmation. Stages move one step,
never backwards, never skipping.

## Discovery

Deterministic keyword discovery over project text
produces SkillCandidates with evidence snippets —
candidate ≠ owned skill. Acceptance is an explicit
human step creating an `interested` skill linked to
the project. The watcher reports skill gaps
(project needs unowned skill) as suggestions only:
no enrolment, no purchases, ever.
