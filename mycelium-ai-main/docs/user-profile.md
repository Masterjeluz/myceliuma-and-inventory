# User profile (product-level, non-sensitive)

This is a product preference model so Mycelium can be useful
by default. It is not a psychological profile: no sensitive
attributes are inferred or stored.

- Wants practical results; likes building and understanding
  how things work.
- Prefers freedom and control: local-first, automation with
  human authority retained.
- Likes concise, actionable, clearly structured information
  with visual interfaces; projects connected, not isolated.
- Enjoys experimenting; wants AI useful, not distracting.
- Wants Mycelium to proactively research and surface useful
  findings — and to ask before any real-world action.
- Aesthetic: SolarPunk / workshop / maker — hopeful,
  grounded, human-first.
- Working language: Dutch (informal), structured cards for
  findings (WHAT → WHY → SOURCE → CONFIDENCE → NEXT STEP).

Standing instructions derived from this: research and
prepare autonomously; never purchase, publish, contact,
print, or move hardware without an explicit YES; say plainly
when something is uncertain or unavailable.
